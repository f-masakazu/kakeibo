# 家計簿アプリ

1つのHTMLファイル + Googleサインインで動く、個人用の家計簿です(メモ帳アプリと同じしくみ)。

- 画面: 出費(現金/カード/電子マネー) ・ 銀行入金 ・ 銀行出金 ・ 損益計算書 ・ 貸借対照表 ・ 設定(⚙)
- 勘定科目・支払先・使った人・電子マネーの種類は、画面から自由に追加できます
- データは端末内と、Googleドライブのスプレッドシート「家計簿データ」に保存されます
  - シート「取引」: 1行1件の仕訳(日付・借方科目・貸方科目・金額・摘要・支払先・使った人)
  - シート「勘定科目」: 科目一覧と、科目ごとの残高(数式で自動計算)
  - シート「リスト」: 支払先と使った人の一覧
- 保存先フォルダは設定画面で指定できます。Googleドライブ上で移動しても使い続けられます

## 使う前の準備(Google Cloud Console)

メモ帳と同じOAuthクライアントIDを使います。

1. 「APIとサービス」→「ライブラリ」で **Google Sheets API** を有効にする
2. OAuth同意画面が「テスト」の場合は、使うGoogleアカウントをテストユーザーに追加する
